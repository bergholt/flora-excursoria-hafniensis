Latin is set in italic, Danish in roman — a reading of the names, since the index marks no language itself. Choose any name to open the page it was printed on: the index gives no translations, but a plant's Latin and Danish names were set on the same page, so part of the pairing is recoverable from it. 129 of 233 pages carry equal numbers of each, and 60 carry exactly one of each — though a page can also hold two unrelated survivors, so the reading is a proposal, not a proof.

The letter rail is the index’s own alphabet, not ours: twenty-five sections, no W and no Y, I and J interfiled, and Æ and Ö at the end — where only Danish names arrive, because in a Latin name Æ was sorted as ae. The Prolog version states those rules as rules and tests them against the printed order.
